# To-Do List App

## Descripción
Aplicación móvil To-Do List desarrollada con Ionic + Angular como parte de una prueba técnica. La aplicación permitirá gestionar tareas, categorizarlas, filtrar por categoría e integrar Firebase Remote Config para habilitar/deshabilitar funcionalidades.

## Objetivo de la prueba
Desarrollar una aplicación base con lista de tareas, soporte para categorías, integración con Firebase Remote Config, optimización de rendimiento y preparación para compilación móvil con Cordova. :contentReference[oaicite:2]{index=2}
